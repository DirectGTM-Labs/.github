# Support and professional enquiries

- Report a reproducible project problem in the affected repository's issues.
- Use an evidence-correction issue for definitions, sources or methodology.
- Use a feature-proposal issue for improvements; state the use case and a
  concrete acceptance criterion.
- Send confidential security concerns according to SECURITY.md.
- Contact contact@mingmingcodes.com for professional enquiries.

Please include relevant files, environment, actual results and the outcome you
expected. Public examples should use synthetic or anonymised data.

DirectGTM-Labs is maintained independently and does not promise a response time.
